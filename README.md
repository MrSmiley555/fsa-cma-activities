# دليل ترخيص الجهات العاملة في الأوراق المالية

دليل تفاعلي ثنائي اللغة (عربي/إنجليزي) لمتطلبات ترخيص الجهات العاملة في مجال الأوراق المالية، وفق اللائحة التنفيذية لقانون الأوراق المالية الصادرة بالقرار رقم خ/11/2026.

- `index.html`: الصفحة كاملة في ملف واحد (HTML + CSS + JS)، بلا أي مكتبات خارجية عدا خطوط Google.
- `regulation-ar.pdf` و`regulation-en.pdf`: نص اللائحة باللغتين.

للاستضافة على خادم الهيئة: انسخ الملفات الثلاثة كما هي إلى أي مجلد على الخادم.
